## 1. Inventory Overview & Methodology

Mīzān al-Ḥadīth (*ميزان الحديث*) consumes a combination of structured classical knowledge graphs, digital text archives, computational concordances, independent scholarly grading datasets, classical commentaries, academic translations, and application-generated topological and vector indices.

Every data artifact contributing to the platform has been audited against:
1. Live filesystem paths and physical byte sizes.
2. SQLite table definitions, row counts, and metadata key-value tables.
3. Python ingestion scripts and database connection strings (`mode=ro`).
4. Upstream Git repositories, Hugging Face dataset cards, and scholarly publications.

### Verification Status Taxonomy
- **`VERIFIED`**: Supported by direct, unassailable evidence in ingestion code, database metadata, and upstream repository records.
- **`PARTIALLY VERIFIED`**: Upstream source and identity confirmed, but specific sub-edition or intermediate scraping provenance has undocumented steps.
- **`LICENSE REVIEW REQUIRED`**: Provenance is documented, but redistribution rights under modern copyright or proprietary publication terms require restricted distribution (e.g. academic fair use only).
- **`UNVERIFIED`**: Insufficient documentary or forensic evidence to confirm origin (none allowed in canonical tiers).
