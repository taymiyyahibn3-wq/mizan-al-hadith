## 1. Executive Summary & Methodology

This document maps all 18 homepage usability findings identified in the Floto Usability Audit to their exact source-code root causes, component files, accessibility implications, minimal remediations, and verification methods.

Each finding has been independently investigated against:
1. `src/app/globals.css` (Design tokens, typography scale, border radii, card flexbox rules)
2. `src/app/page.tsx` (Homepage layout, hero section, search form, section headers)
3. `src/app/components/BookShowcase.tsx` (Sihah Sittah 3D bookshelf cards, edition badges, provenance notes)
4. `src/app/components/SiteChrome.tsx` (Top navigation bar, mobile drawer, action links)

## 3. Preserved Scholarly Invariants

During remediation of these 18 issues, the following architectural invariants are strictly preserved:
1. **Zero Database Changes:** Canonical database files (`hadith-kg.db`), schema definitions, and SQL queries remain untouched.
2. **Hadith Data & Numbering:** No changes to hadith identifiers, grading levels, narrator biographical records, or isnād linkages.
3. **Scholarly Provenance:** Every book cover's edition provenance (e.g. Būlāq 1311 AH, Al-Amīrah Imperial Press, Halabi 1st Edition) remains explicitly visible, attributed, and documented.
4. **Arabic Calligraphy & Script Integrity:** Arabic fonts (`Amiri`, `Scheherazade New`) retain correct leading and vocalization rendering.
5. **API & Route Contracts:** All endpoints (`/api/stats`, `/api/books`, `/api/search`) and page routes remain 100% intact.
